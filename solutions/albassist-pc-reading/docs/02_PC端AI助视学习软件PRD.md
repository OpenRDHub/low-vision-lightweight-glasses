# PC 端 AI 助视学习软件：产品需求文档 V1.0

日期：2026 年 10 月 10 日。角色：规划。适用对象：本队开发、测试与路演成员。

本文是本队拟开发的**AI 助视眼镜 PC 视觉参考端** PRD，不是主办方完整眼镜 PRD 的改写，也不是已实现功能说明。最终产品形态是面向白化病低视力儿童及青少年的分体式 AI 助视眼镜；当前 Windows PC 负责承载主要交互视觉、算法验证和可重复演示，后续再迁移到眼镜显示、眼镜摄像头、分体计算端和实体控制。PC 阶段不是普通桌面软件终态，也不等价于已完成光学、遮光、防抖、续航、佩戴或真实 AR。用户已明确：PC 软件先行，AI 必须有，硬件接口后续对接，不能依赖现场唯一眼镜。本文据此提出可独立开发且迁移友好的首版范围；患者效果、学校准入、学习机兼容及眼镜接口均未验证。产品形态与迁移约束详见 `docs/产品形态与迁移边界.md`。

快速阅读：第 1—4 节确定做什么、为谁做；第 5—8 节规定首版功能、AI 与 AR；第 11 节规定怎样验收；第 13—14 节说明实现顺序及待确认问题。

## 1. 产品定位与本版决策

**产品定位：面向白化病低视力中小学生的室内学习阅读工具，使用自己的相机和 PC，把课本／讲义原图放大呈现，并用本地 AI 将选中文字转换成可调字号的大字阅读版，保持与原图位置对应。**

首版不是"滤镜大全"，也不是通用 AI 学习机。核心任务是：学生找到想读的一段内容，自己看，必要时切到大字阅读版，然后能回到原文继续看图、公式或上下文。语音是辅助通道。

| 决策 | 本版选择 | 原因与限制 |
|---|---|---|
| 主用户 | 仍有可利用视觉、需要放大或调整显示的白化病儿童及青少年 | 以学习需求和实际阅读表现选择，不按统一的 0.02 视力分组 |
| 主场景 | 审内课本、讲义和作业中的印刷文字阅读；首轮在居家／可安排的体验场地验证 | 自带设备较容易取得真实细节；无需等待学校准入或远距长焦设备 |
| 首版平台 | Windows PC 本地软件，自带屏幕 | 用户指定 PC；具体测试机配置在开发前记录 |
| 必须交付的 AI | 本地学习模型的文字检测与识别，驱动大字重排和原图定位 | 有可测量的输入、结果与阅读用途，不以聊天接口代替助视 |
| 首版呈现 | 原图视觉助视＋AI 大字阅读，两种视图切换 | 保留图表和真实笔画，OCR 结果可回查 |
| AR／眼镜 | 输出适配的后续验证项 | 未知 SDK 与投屏接口；PC 叠加标记不宣称已完成完整 AR |
| 硬件 | 相机、屏幕、支架为必要输入输出；实体按钮等按实际缺口选用 | 不研发光学、主板或整机，不强制采用 T5 |
| 课堂板书 | 扩展场景，有可辨认的远距输入后再验证 | 相机采不到笔画时，软件无法保证高倍率真实清晰度 |

## 2. 人群、需求与使用者

### 2.1 核心用户的功能条件

本版优先服务符合以下使用条件的学生：能在合适字号、对比度和观看距离下辨认部分文字；常规配镜后仍存在学习材料读取困难；愿意尝试屏幕阅读，并能使用简单按键或触控。是否适用要经本人体验确定。

普通眼镜可矫正合并的近视、远视和散光；本软件补充内容呈现，不替代配镜。患者视觉能力、畏光、眼震、头位和偏好有差异；不得将某一人的设置作为所有患者默认最优值。小数视力不表示剩余视觉百分比，也不单独决定放大倍率。

| 使用者 | 使用目的 | 产品需要支持什么 |
|---|---|---|
| 学生，核心使用者 | 看清内容，找到下一段，必要时听文字 | 少操作、大字控件、原图返回、明确阅读位置 |
| 家长／老师，辅助使用者 | 首次摆放设备、调整显示、提供材料 | 易懂的初始设置和状态，能协助但不必全程代操作 |
| 需求代表／体验者 | 判断显示与操作是否适合 | 可调参数、可比较模式、可记录主观反馈 |
| 本队开发／测试人员 | 复现输入、模型错误和性能问题 | 去身份化的测试样例、设备与模式记录；诊断数据不占学生主界面 |

### 2.2 要验证的用户问题

| 问题 | 当前依据 | 拟解决方式 | 待验证的效果 |
|---|---|---|---|
| 普通大小文字难辨认 | 赛事需求强调自主视觉与放大 | 原图选区放大、显示模式调整 | 在个人适合的设置下能读到更多内容 |
| 放大后丢失位置、换行困难 | 高倍率缩小视野带来的工程问题 | 原图全局预览、阅读段与原文框对应、上一段／下一段 | 找下一段更省操作，少丢行 |
| 扫描图片不能像数字文本一样改字号 | 图像与可重排文本的形式差异 | AI OCR 后以可调字号和行距重新排版 | 在保持文字正确的前提下减少水平来回移动 |
| AI 识错时难发现 | OCR 的已知技术边界 | 原图随时回查、未核对提示、疑似错误标记 | 用户不会把模型结果误当原文保证 |
| 特定内容靠视觉仍难读取 | 个体需求，需本人确认 | 可选离线朗读并定位当前段 | 获得额外通道，不强迫放弃视觉阅读 |

## 3. 场景与首版边界

### 3.1 主场景：课本／讲义的一段印刷文字

学生在室内把纸面材料放到相机前，先在屏幕看原图；冻结一帧，选择要读的段落，触发 AI。软件提供两种读取方式：原图局部放大，或者大字阅读版。读完后切换下一段或回到整页定位。

典型内容为中文正文、英文正文和少量中英混排。首版 AI 验收不覆盖手写作业、黑板手写字、数学公式结构、复杂表格与多栏论文。

### 3.2 扩展场景

| 场景 | 进入条件 | 首版处理 |
|---|---|---|
| 教室内板书／投影 | 学校允许使用，输入设备能采清内容 | 保留输入适配能力；不作为首版通过条件 |
| 老师提供的电子截图 | 有可用的图片文件 | P0 支持 PNG／JPEG 导入 |
| 学习机／平板 | 设备允许安装、性能通过测试 | 后续适配，首版不交付 Android |
| AR／近眼眼镜 | 有确定的显示输入和实测配置 | 接入实验；无接口时 PC Demo 独立运行 |

### 3.3 不纳入首版

不纳入：提高生理视力、眼震治疗、全场景"无损 10×"、生成式补全、AI 自动做题、通用聊天、户外导航、人脸识别、眼动追踪、双目立体重建、整机续航与成本达标。

## 4. 产品目标与预期效果

| 层级 | 要达成什么 | 如何判断 |
|---|---|---|
| 软件可用 | 自带相机／图片输入后，可完成原图阅读与 AI 大字阅读循环 | 另一名队员能在指定 PC 上按说明复现，无需眼镜与网络 |
| AI 有作用 | AI 结果真正改变阅读呈现，并能定位回输入内容 | 用实拍材料检测、识别、重排；模型关闭后该能力确实不存在 |
| 内容可信 | 识别结果可回查；公式、错误和低质量输入不被隐瞒 | 逐字标注、错误样例、原图返回和异常测试 |
| 用户体验改善 | 至少对部分目标用户，读同等难度内容更省时／更少丢行 | 个体对照测试；不预填有效率 |
| 后续可接入 | 输入、处理和输出可独立替换 | PC 闭环与眼镜／学习机适配状态分别报告 |

## 6. AI 的具体责任与技术边界

### 6.1 首版 AI 任务

**输入：**冻结帧或本地图片中的一个选区。**模型：**本地文字检测模型＋中文／英文识别模型。**输出：**文字块、原图位置、识别文字及置信信息。**用户价值：**生成可调字号的阅读版，减少水平扫描，找到原文。

### 6.2 AI 输出与原图的契约

每次识别任务至少有 `document_id`、`frame_id`、`request_id`。每个结果块至少保留 `block_id`、原图坐标、识别文字、模型与版本信息；置信信息按模型实际能力保存，不能伪造。

重排只改变字号、行距、换行和背景；不得自动润色、补字、答题或更正数字。所有结果均可回查原图；即使模型置信度高也显示未核对状态。

### 6.3 暂不把大模型或超分作为必需

首版不需要调用云端通用大模型，OCR 可以离线运行。生成式超分可能制造错误笔画，不用于证明内容真实。

## 7. AR 与眼镜的定位

首版交付名称为"PC 端 AI 助视学习软件"。它在相机图像上叠加选区和阅读位置，属于图像增强与二维标注；不充分证明实现了完整 AR 系统。

眼镜作为近眼显示接收 PC 画面，首先是近眼显示接入；是否构成赛事认可的 AR 功能，需根据设备能力和主办方口径判断。

## 8. 用户操作流程与界面要求

### 8.1 完整阅读循环

```
选择相机或导入图片 → 原图预览(放大/对比度) → 冻结并选择一段
→ 本地 AI 检测与识别 → 大字重排与当前段定位 → 下一段或回到原文
```

### 8.2 两种主视图

**原图视图：**主区域显示当前画面或冻结图片；全局预览显示选区位置；控件为缩放、显示模式、冻结／恢复、识别选区。

**大字阅读视图：**主区域为重排文字；保留"看原图""上一段""下一段"和字号调整。当前段高亮用边框／背景变化。

### 8.3 交互与状态

| 状态 | 界面行为 | 操作边界 |
|---|---|---|
| 无输入 | 显示选择入口 | 不自动开启摄像头 |
| 实时预览 | 显示当前画面 | AI 不逐帧阻塞预览 |
| 已冻结 | 明确冻结标记与选区 | 识别只针对该帧 |
| 正在识别 | 可取消、可看原图 | 后台识别不锁窗口 |
| 阅读结果 | 显示未核对说明与原图返回 | 旧结果不覆盖新材料 |
| 输入／模型失败 | 保留可用原图，提示恢复 | 区分相机/模型/识别失败 |

所有 P0 操作可通过键盘完成。

## 9. 平台、数据与性能要求

### 9.1 PC 首版

Windows 10／11、x64 CPU 本地运行，不要求独显。模型、字体和离线资源随发布方案准备；启动后不依赖联网下载。

### 9.2 图像与偏好数据

默认不上传图片、音频或识别文本，默认不录像、不保存输入图像。仅保存用户主动选择的显示偏好。

## 10. 验收方案

### 10.1 固定测试材料

12 张印刷材料照片（中文、英文、中英混排各 4 张）+ 6 张失败／边界材料。

| 编号 | 验收项 | 初始目标 |
|---|---|---|
| A01 | 独立阅读闭环 | 所有 P0 功能可复现 |
| A02 | 离线 AI | 断网完成检测、识别与重排 |
| A03 | OCR 内容质量 | CER ≤5% |
| A04 | 原图对应 | 100% 有有效原图位置 |
| A05 | 识别响应 | P95 <2 秒 |
| A06 | 预览性能 | 1080p ≥25 FPS |
| A07 | 画面延迟 | P95 ≤200 ms |
| A08 | 界面响应 | P95 ≤100 ms |
| A09 | 稳定与恢复 | 30 分钟无崩溃 |
| A10 | 失败处理 | 边界样例均可回到原图 |

### 10.2 用户效果验收

对照 A（原图放大）vs 方案 B（AI 大字阅读），交替顺序，记录准确性、耗时、操作负担和可接受性。

## 11. 实现顺序

| 阶段 | 完成什么 | 退出条件 |
|---|---|---|
| M0 | 设备与模型可行性 | 实拍印刷段落，验证本地模型 |
| M1 | 原图助视基线 | 预览/冻结/选区/放大/回整页 |
| M2 | AI 阅读闭环 | 识别→重排→定位→回查；取消/错误恢复 |
| M3 | 验证与改善 | 固定集、性能记录、用户对照 |
| M4 | 选择性扩展与交付 | 朗读等 P1；有接口再试眼镜 |

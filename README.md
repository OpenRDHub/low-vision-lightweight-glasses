# Lightweight Low-Vision Assistive Glasses · 轻量化低视力助视眼镜

> 「罕见·无界」黑客松赛题 · 项目1：白化病 + 弱视力 + 轻便眼镜
> 由 [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)发起，患者共创 · 一个赛题 = 一个长期开源项目

为白化病等低视力群体打造**既适用于日常出行、又适用于课堂看黑板**的轻量化助视眼镜。

## 🧭 背景与真实处境

白化病等低视力人群常伴有**畏光（Photophobia）**、远距离文字和图像识别困难，现有手持助视设备操作不便，也难适应高频日常场景。

**用户画像**（来自「月亮孩子之家」公众号 92 篇存档逐篇精读 + 444 样本调研）：

- 视力谱系 0.01 ~ 0.2，普遍伴随眼球震颤（Nystagmus）与畏光；
- 家庭年收入均值约 3.4 万元，就业率 70%，**辅具自费率高达 93%**，46.19% 的受访者存在焦虑情绪；
- 痛点分级 **P0**：看黑板远距放大 / 近距防疲劳 / **外观不像辅具** / 价格可负担。

**核心设计约束**：

| 约束 | 说明 |
|---|---|
| 眼球震颤 | 对图像稳定 / 防抖算法提出硬性要求 |
| 畏光 | 需要亮度管理 |
| 视力 0.1 ~ 0.3 | 需要高对比度、大字体 |
| 两用便携 | 出行 vs 课堂双场景 |

## 🎯 项目目标

设计可日常佩戴的轻量化助视眼镜，实现实时画面放大与灵活调节，同时兼顾视野、舒适度、续航和外观。

**正在求解的核心设计问题**：

1. 白化病患者视力情况的具体数值分布？
2. 眼球震颤频率 / 幅度对图像稳定算法的要求？
3. 现有头戴显示（HMD）产品的核心不足是什么？
4. 课堂场景（3–10 m 距离）需要多少倍放大？
5. 防抖算法 + 屈光补偿 + 亮度管理如何整合？
6. 设备形态：AR 眼镜 vs 挂载手机 vs 独立设备？

## 📊 已完成调研（社区知识库）

- **竞品·国际头戴设备**：eSight / NuEyes / IrisVision / Envision / OrCam 五家全型号参数 + 官方价格 + 白化病适配评估
- **竞品·国内在售与渠道**：国内在售型号、电商真实价格、残联集采中标价、补贴上限与渠道体系

- **竞品·消费级 AR 路线**：XREAL / Rokid / 雷鸟 / 华为等作为助视平台的可行性评估
- **用户洞察**：月亮孩子之家公众号全部 92 篇存档逐篇精读，原话引用均可溯源

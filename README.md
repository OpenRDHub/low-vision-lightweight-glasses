# Albinism AR+AI Assistive Glasses · 白化病低视力人群 AR+AI 助视眼镜

面向白化病低视力人群的**分体式 AR+AI 助视眼镜**，同时解决三件事：**看得清**（光学长焦预采样 + AI 超分辨率无损放大）、**稳得住**（抗震颤防抖）、**带得出门且买得起**（轻便隐蔽外观 + ¥2,000–3,000 价格带）。这三件事拆开都有人做，**合二为一、且专为白化病低视力设计的，目前市面上没有**。

> 定位：视觉康复辅助器具，非医疗诊断设备，不替代眼科检查与专业诊疗。

## 🧭 一、疾病认知：不是「看不见」，是「看不清」

白化病（Albinism）是由黑色素合成或转运基因突变引起的先天性遗传性疾病，属罕见病；患者皮肤、毛发、眼部均缺乏黑色素，是全身性疾病而非单纯眼病。

| 指标 | 数值 | 说明 |
|---|---|---|
| 中国人群发病率 | 约 1/18,000 | 全球约 1/15,000–1/20,000 |
| 中国患者估算 | 约 10 万人 | |
| 典型矫正视力 | 0.01–0.3 | 能看见光和形状，看不清细节 |
| 伴眼球震颤比例 | >90% | 先天性高频不自主眼球抖动 |

临床分型：OCA1（视力多在 0.1 以下）、OCA2/OCA4（约 0.1–0.3，色素残留较多）、OA1 眼白化病（约 0.1–0.4，X 连锁，仅眼部受累）。目前无根治手段（AAV-TYR 基因治疗尚在 I 期临床，预计 2030 年底完成）——**未来 3–5 年助视需求刚性不变**。

### 核心病理机制（决定产品方向的起点）

月亮孩子之家创始人/验配师关禄（本人为白化病患者）2026-09-24 需求问答的核心结论：**白化病低视力不是「模糊」，是「细节少」**——「普通人的眼底是 5000 万像素，白化病患者的眼底可能只有 500–2000 万像素」。

由此派生三条硬约束：

1. **常规配镜基本无效**（除非同时伴屈光不正）
2. **唯一有效路径是把图像放大到能辨识的程度**
3. **眼球震颤不是主要障碍**——人眼分辨一个文字只需 1/10 秒注视时间，提供足够的注视窗口即可

> ⚠️ 认知修正：项目早期曾推断「用户最需要 OCR 朗读而非放大」。经关禄病理机制说明，此判断需修正——白化病患者保有 0.01–0.3 残余视力，核心诉求是**「自己看清楚」**而非「听朗读」；OCR 朗读定位为辅助增强功能（对比：全盲人群才以朗读为第一需求）。

## 👤 二、用户画像与痛点分级

中国罕见病联盟 2019 调研（444 例确诊患者）：平均年龄 11.34 岁（儿童是主体，家长是购买决策人）；成年患者个人年收入均值 34,239 元；辅具自费率 93%；「有一点焦虑或沮丧」高达 46.19%；公众号/病友组织是第一信息渠道——**社群即渠道**。

**痛点分级**：

- **P0（不解决就不买）**：① 看黑板（远距放大）——9 年跨度 10+ 篇反复出现，「坐第一排也看不清黑板粉笔字」；② 近距阅读防疲劳——痛点是「疲劳+效率」而非单纯看不清，护眼是硬指标；③ **外观不像辅具**——「戴上就像宇航员所以她不喜欢这款很好用的头戴式助视器」，外观决定产品生死，功能其次；④ 价格可负担——DIY 2,630 元、展迈 M1 699 元是社群认可锚点
- **P1（强烈渴望）**：抗震颤防抖（现有产品几乎无一正面解决）、遮光/畏光适配、轻便能戴着走、看黑板+低头写字无缝切换、离线 OCR 朗读
- **P2（惊喜项）**：人脸识别+语音提示（社群自己已经在想象）、夜间增强模式（群体「喜欢夜晚出行」未被覆盖）、电脑/手机投屏联动、大字试卷/教材配套

**用户选择规律**（莫爸十年验配经验）：好用+方便+孩子自愿，缺一不可——平板式电子助视器最成功（同学觉得「潮」）；头戴式功能再好因「像宇航员」被拒，**外观社会化 > 功能**。

## 🛠 三、核心功能需求

| 功能 | 关键指标 |
|---|---|
| **高倍无损放大（第一刚需）** | 等效阅读倍率 >10×（覆盖 10 米外板书）；AI 超分实现「感知级无损」，禁止纯插值放大；光学长焦预采样+多帧融合；无极变焦+注视点放大 |
| **抗震颤防抖（差异化核心）** | 光学防抖+多帧融合 AI 防抖双层方案；保证 ≥1/10 秒稳定注视时间；解决「放大后画面晃动更明显」的行业通病 |
| **遮光/畏光适配（必要条件）** | 外挂磁吸挡光片或电子变色镜（液晶）；抗眩光、亮度自适应；户外强光必须可用；偏振/滤光一体化+防紫外线 |
| **OCR 朗读（辅助增强）** | 必须离线（课堂/户外/考场无网络，离线是残联采购硬指标）；响应 <2 秒；中英文；以天使眼评测缺陷为现成验收清单（竖排/分栏/形近字/续航） |
| **高对比度增强** | 关键信息高对比度描边、文字放大、多种色彩/对比度模式 |
| **外观与佩戴** | 看起来像一副普通墨镜（与畏光人群戴墨镜习惯天然融合）；重量参考 Envision <50g / NuEyes 102g / eSight 170g；磁吸屈光镜片；分体式（眼镜端做轻、计算端做重） |
| **续航与交互** | ≥8 小时（覆盖全天上课/工作）；极简交互；静音/隐私模式 |
| **差异化增强（第二/三版）** | 人脸识别+姓名播报、物品/条码识别、夜间增强模式、电脑/手机投屏联动、障碍物提醒（P2） |

**非功能需求**：主力 SKU ¥2,000–3,000（BOM：单目约 ¥410–715 / 双目约 ¥710–1,215）；低延迟；大视场角（FOV）；低蓝光护眼；**禁止平台锁定**（Windows >90%、Android >70% 用户不能放弃）。

## 📊 四、竞品格局与市场空档

**国内价格三段式**：手机+VR 外挂（¥560–699，不解放双手仅限室内）→ 手持/平板电子助视器（¥1,358–9,180，占用手无法边看边记、无防抖）→ 头戴 AR/VR 一体（¥19,800–39,800，贵重、续航 2–4h、插值放大模糊）。

**关键发现**：
- **¥1,500–3,000 是价格真空带**——瞳者（¥3,399，无高倍放大）与 Luna S（¥1,358，仅手持）之间，没有「高倍放大+OCR 朗读+解放双手」的产品
- 残联补贴上限：地市级 ¥6,000、深圳市 ¥12,000 → 建议设计 ¥5,800 / ¥9,800 双档 SKU，补贴即可覆盖
- 国际两派分裂：视觉增强派（eSight Go ¥3.5 万 / NuEyes ¥2.8 万 / IrisVision ¥2.3 万，无物理遮光、无眼震方案）与 AI 转述派（Envision / OrCam，完全没有放大能力）——**白化病患者既要放大又要朗读，恰好落在两派之间的空档**；最核心结论：没有任何一家同时满足「高倍放大 + OCR 朗读」
- 技术空白点：眼震+畏光（唯一无人认真做的生态位）、物理遮光、离线 OCR、平台开放
- 政策窗口：2026 版《中国康复辅助器具目录》新增「视力障碍智能辅助设备」类目；浙江/上海等地已有智能助视设备入围路径；2027 年起竞争将从产品参数转向「省级集采目录卡位」

## 🧪 五、技术路线：三档逐级验证

| 档位 | 内容 | 目的 |
|---|---|---|
| 一档：现货改造 | 现有消费级 AR 眼镜+免费 APP（Seeing AI 等） | 零成本验证放大/OCR 真实体验 |
| 二档：半自研 | 自定义 Launcher+关键模块优化 | 整合体验，验证核心算法 |
| 三档：全自研分体式 | 眼镜端做轻+计算端做重 | 实现 ¥2,000–3,000 价格带 |

关键技术点：AI 超分（光学长焦预采样+多帧融合）、双层防抖、离线 OCR 引擎、系统 TTS、人脸识别、磁吸/电子变色遮光。

**待验证问题**：放大倍率是否达标（残联核心指标）、摄像头对焦范围、OCR 响应速度（课堂 <2 秒）、离线能力、眼震防抖实际效果（找眼震严重用户实测）。

## 💰 六、商业模式（公益 + 残联采购支付）

进入路径：先公益试点（月亮孩子之家等免费发放试用）→ 积累真实案例 → 申请创新辅具目录 → 进入残联采购。渠道即社群——月亮孩子之家年均组织团购/发放 140–160 人。

营销要点：用户要「独立」而非「帮助」、要「普通」而非「科技」、怕买错就给「租赁/试用」、怕伤眼就讲「护眼」、怕改变习惯就「渐进」。**文案禁忌：禁用残缺叙事（不说「帮助盲人看世界」）**。

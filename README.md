# Lightweight Low-Vision Assistive Glasses · 轻量化低视力助视眼镜

> 项目1：白化病 + 弱视力 + 轻便眼镜 —— [OpenRD 罕见病开源社区](https://github.com/OpenRDHub)

为低视力群体打造日常可用的轻量化助视眼镜。

## 真实处境

白化病等低视力人群常伴有畏光、远距离文字和图像识别困难，现有手持助视设备操作不便，也难适应高频日常场景。

## 挑战方向

- 设计可日常佩戴的轻量化助视眼镜
- 实现实时画面放大与灵活调节
- 兼顾视野、舒适度、续航和外观

## 关键词

`白化病` `低视力` `助视眼镜` `可穿戴` `实时放大`
